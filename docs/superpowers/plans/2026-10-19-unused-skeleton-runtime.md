# Удаление неиспользуемого Phantom UI

Из RootLayout удалены глобальный SSR CSS библиотеки и PhantomUiBootstrap.
Этот bootstrap импортировал Phantom UI на каждом маршруте, кроме точного `/`.
В исходниках не осталось потребителей `<phantom-ui>`; skeleton в кабинетах и
оформлении реализованы обычным CSS. Удалена ненужная JSX-декларация.

Из package.json/lock удалены Phantom UI и шесть его исключительных зависимостей
Lit. Сравнение lock до/после подтвердило: других новых пакетов или изменений
version/resolved/integrity нет. Общие AuthSessionBootstrap, CartSyncBootstrap,
AppEnvironmentProvider, SplashBoundary, PWA и аналитика сохранены. Новый Provider
и замена библиотеки не добавлялись. Backend и пользовательские данные не менялись.

## Измерение

Сравнивались отдельные production standalone сборки до/после: единственные пять
изменённых файлов — layout, bootstrap, декларация, package.json и lock.
Общий настоящий PostgreSQL17/MinIO/ASGI, синтетические128 товаров/1724 SKU,
восемь публичных профилей и лендингов. Chromium без замедления CPU/сети:
по четыре холодных контекста на вариант и маршрут,16 открытий с чередованием.

CDP encodedDataLength включает заголовки. Gzip-эквивалент тел скриптов,

байтов, без нового утверждения об LCP, скорости телефона или production.
