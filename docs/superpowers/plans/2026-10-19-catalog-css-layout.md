# Сетка каталога без перестройки после первого показа

Основной редактор товаров — новый кабинет производства → «Пресеты».
Старый `/admin/models` перенаправляет в `/production?section=presets`.

## Изменения

ServiceProductGrid раньше распределял товары по отдельным колонкам с помощью
`useSyncExternalStore` и определения ширины окна. Сервер начинал с двух колонок,
браузер на широком экране пересоздавал распределение в четыре. В предыдущем
локальном прогоне это давало CLS 0,3025.

Теперь товары находятся в одном списке в порядке ответа API. CSS Grid выбирает
две колонки до 600px, три от 600px и четыре от 900px. При изменении ширины React
не переносит карточки между родителями; раскрытие и фокус сохраняются.

Изменение поведения: при раскрытии карточки следующая строка сдвигается целиком.
Соседние карточки сохраняют свою высоту. Это обычная сетка строк с единым
визуальным и клавиатурным порядком, без независимого уплотнения колонок.

Высота и прокрутка сервисной оболочки в globals.css теперь определяются
наличием отрендеренного `[data-service-view]`. Начальный HTML получает нужные
правила до гидратации, без ожидания атрибута из AppEnvironmentProvider.
Контекст окружения, auth/cart bootstrap и остальные оболочки сохранены;
нового Provider, сетевого запроса или кеша нет.

## Проверка

Production-сборка Next 16.3.8, настоящие ASGI/PostgreSQL17/MinIO, 128 товаров,
1724 SKU, восемь профилей и восемь сообществ. `.env` проекта исключены из копии;
внешние провайдеры не настроены. Собственное временное окружение удаляется.

Общий browser helper `frontend/scripts/fixtures/storefront-layout.mjs` проверяет:

- Серверный HTML без JavaScript при 320/390/599/600/736/899/900/1280px:
  число колонок, порядок 24 ID, геометрию и отсутствие горизонтального overflow.
- Три свежих desktop-контекста с удержанием загрузки JS: четыре колонки до и
  после гидратации, те же DOM-узлы, координаты и размеры с допуском 1px,
  отсутствие повторного browser GET начального списка. CLS во всех трёх — 0.
- Клавиатуру: скрытые действия не попадают в Tab, Enter раскрывает карточку,
  фокус проходит к избранному и ссылке конструктора. Изменение ширины на всех
  восьми размерах сохраняет раскрытие, DOM-узел ссылки и фокус.
- Раскрытие сдвигает следующую строку, соседние карточки не растягиваются.
  Догрузка 24 → 48 сохраняет порядок и уникальные ID.

617 frontend-тестов прошли без ошибок и пропусков. TypeScript/production build
прошли, ESLint — без ошибок, одно прежнее предупреждение alt-text.
Helper включён в `npm run check:admin-catalog`, который использует отдельный
standalone Next и синтетический HTTP API; проверка настоящего стека выполняется
отдельно. Это локальные проверки, запуск этого gate в Actions здесь не заявлен.

Backend продукта не менялся; предыдущие 1190 backend/0skip не повторялись.
WebKit не установлен: Safari, настоящий телефон, нагрузка и production этим
этапом не проверены. Нового сравнения LCP нет. Объём изображений и остальных
ресурсов, полные DTO и общие ворота выпуска остаются в работе.
Commit/push/deploy не выполнялись.
