# Актуальный замер главной и каталога

19 октября 2026. Код приложений не менялся. Измерен текущий результат после
предыдущих изменений запросов, раскладки, превью аватаров и удаления Phantom UI.

## Условия

Свои свежие PostgreSQL17 и MinIO, настоящий ASGI после Alembic head0080;
128 товаров,1724 SKU,8 опубликованных людей и8 сообществ. Фото загружены через
AvatarService, файлы товаров/сообществ читаются из MinIO. Ответы API не подменялись.
Отдельная production standalone сборка Next из текущих исходников; identity,
catalog writes и CRM включены. `.env` не копируется. Внешние провайдеры выключены.

Восемь холодных контекстов Chromium: по три на маршрут при390×844, CPU×4,
задержке150мс, скачивании200000 байт/с; по одному на1280×900 без замедления.
HTTP-кеш выключен, Service Worker заблокирован, бизнес-состояние гостя пустое.
Скрыт только consent banner. Случайный HTML100007 байт подтвердил замедление:
545мс; каждый мобильный прогон сообщил применённое CDP-правило.

## Результат

| Маршрут | Мобильный LCP, медиана | CLS во всех прогонах | Полученные байты, медиана |
| --- | ---: | ---: | ---: |

| Каталог | 2200мс | 0 | 1345960 |

LCP главной — надпись GARMENT, каталога — фото товара. Это не готовность всех
карточек или интерфейса к действию. DOM карточек появился примерно на178/175мс,
но это также не время получения их фотографий. Единственные длинные задачи
в мобильных медианах заняли51/52мс. Десктопные одиночные LCP60/68мс описывают
только этот быстрый локальный стенд.

HTML без JavaScript содержит4 товара,4 человека и4 сообщества главной,24 товара
каталога. Браузер не повторяет начальные GET списков и не читает отсутствующую
корзину нового гостя. Начальный список товаров делает2 SQL; люди и сообщества
по1. Во всех восьми прогонах нет pageerror или горизонтального переполнения.
Ожидаемый401 /api/auth/refresh у гостя записан отдельно и не выдан за500-ошибку.

Крупнейшие общие ресурсы остаются видимыми элементами корзины: видео273599 байт
и фон165899 байт. Их суммарная передача439498 байт — около40% главной и33%
каталога на этом наборе. Это основание для отдельного эксперимента с ресурсами,
а не доказательство причины LCP. Первое фото каталога сейчас loading=lazy;
изменение приоритета требует контролируемого сравнения, здесь оно не выполнялось.

## Границы

Ранний замер1248/2208мс выполнен другим запуском, до нескольких разных правок.
Нынешние1204/2200мс не доказывают ускорение в процентах и не позволяют приписать
разницу конкретному изменению. Байты учитываются за12с после DOMContentLoaded:
CDP encodedDataLength с заголовками завершённых ответов и полученные data events
незавершённых. ResourceTiming responseStart здесь исключает искусственную
задержку заголовков и не является пользовательским TTFB замедленного соединения.

Это не физический телефон, полевые Core Web Vitals, нагрузочный тест или
production. Linux Docker сборка идёт отдельно и HTTP ещё не прошла. Полные
1266 backend/621 frontend относятся к прежним этапам; свежие82 проверки
deployment-скриптов — к непрерывному окну backup. Исходники приложения неизменны,
поэтому эти полные наборы не повторялись. Свои процессы, БД, объекты, временная
сборка и приватная конфигурация удалены. Commit/push/deploy отсутствуют.

Доказательства в каталоге задачи: `release-runtime-results.json` (8 прогонов,
3 проверки), `release-runtime-api.jsonl`, `release-runtime-seed.json`,
`release-runtime-build.log`, скриншоты mobile/desktop главной и каталога.

Карта дополнена актуальным срезом:20 offline suites прошли,667 ссылок на файлы
и строки корректны;320/390/736 px, без HTTP/JS/переполнения. После уточнения
подписей повторно прошла проверка изменённого раздела. Скриншоты страниц и карты
просмотрены. Inline источник998385 байт, standalone HTML работает без сети.
