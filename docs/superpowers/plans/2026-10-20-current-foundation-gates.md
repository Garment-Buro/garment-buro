## Сверка с исходной задачей

Локальная подготовка новой кодовой базы выполнена по проверяемым направлениям:

| Запрос | Реализация и подтверждение |
| --- | --- |
| Убрать прежний каталог и редактор лендинга | Прежние CatalogScreen/LandingPage, `/admin/editor`, SQLite facade и файловые landing settings удалены; factory подключает модульные router. `/admin/models` перенаправляет в производство → «Пресеты». Browser gate проверяет redirect и основной редактор. |
| Постоянные данные вместо демо в браузере | Избранное, проекты, корзина, профили и сообщества используют API/PostgreSQL с ownership. Полный suite включает contract и PostgreSQL integration для favorites, customer projects, cart revisions, public profiles, owner landings. Частные файлы проходят media API/MinIO. |
| Архитектура и границы запросов | Маршруты → сервисы → repositories → модели; браузер работает через общий same-origin API, внешние провайдеры обслуживает backend. Версии, серверная цена, конфликт/replay проверены API и настоящим Next HTTP. |
| Главная, каталог и лишние чтения | Первые страницы получаются сервером, общие paged resources управляют поиском/append/отменой/повтором. PostgreSQL plan tests проверяют storefront/options/images, редактор, справочники и production details. Локальные измерения витрины сохранены отдельно; production-ускорение не заявляется. |
| Запуск и хранение | Lifespan освобождает частично запущенные ресурсы, отдельные миграции и проверка head. Production PostgreSQL/MinIO и ограниченные runtime-роли проверены свежим Compose; корзина сохраняется без Redis. |
| Логирование | Структурированные события stdout, request ID, шаблоны маршрутов без body/query/token; observability и Nginx privacy проверены отдельно и внутри полного gate. |
| Общие компоненты и редакторы | Основной товарный редактор в «Пресетах»; каталоги и формы используют общие модули чтения/записи с отдельными правами. Статический граф содержит 194 компонента, достижимых от маршрутов; два V2 остаются намеренными используемыми обёртками. |
| Понятное объяснение | Локальная HTML-карта содержит описания файлов, providers, оболочки страниц, пути запросов/данных, компоненты и текущие ограничения проверки. Все 33 offline-checks прошли, 710 ссылок валидны. |

Сохранённые миграции, явный перенос локальных черновиков, короткий grace period
старых сессий и отдельные учебные production-сценарии описаны в основном обзоре.
Они не возвращают старый файловый backend в runtime. «Кодовая база подготовлена»
означает проверенный локальный кандидат; публикация, рабочие данные и реальные
эффекты провайдеров остаются за указанной выше границей этого результата.
