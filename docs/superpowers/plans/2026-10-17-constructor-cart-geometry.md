# Геометрия дизайна при повторном открытии корзины

Предыдущий этап — реальный SKU и отделение роста от длины изделия — завершён
и проверен. Текущий этап: cart edit восстанавливает украшения, но не сохранённую
геометрию и изображения. При изменении каталога меняется отображение дизайна.
У прямоугольного холста проекта при переносе в корзину теряется pixel mapping.

- [x] Воспроизвести изменённые замеры и прямоугольный холст тестами.
- [x] Сохранять минимальные canvasPixelSize/modelBounds вместе с customization
  для корзины/заказа; восстановление старых строк использует их сохранённые
  физические размеры, а не актуальные замеры каталога.
- [x] Использовать одну геометрию при восстановлении украшений/рендере/записи;
  явная смена размера/цвета меняет товар, изменение только роста сохраняет холст.
- [x] Не дублировать геометрию в серверном документе проекта: его существующие
  поля верхнего уровня остаются каноническими, serializer отделяет transport.
- [x] Валидировать необязательную геометрию на backend при приёме корзины/заказа.
- [x] Проверить тесты, lint/build, browser API/cart/order roundtrip, карту/журнал.
