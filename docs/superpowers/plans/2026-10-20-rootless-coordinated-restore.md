# Согласованный backup/restore на настоящем rootless Docker

MinIO сохраняется по решению владельца проекта. Проверка 20.10 использовала
только синтетические данные в отдельной VM, удалённой после проверки.

Настоящий deploy/scripts/backup-server.sh, без подмены Docker, останавливает
активный writer, приложение и MinIO, создаёт проверенный пятифайловый bundle
и возобновляет прежний набор сервисов. Обнаружено реальное нарушение:
Compose start повторно запускал database-role-init через зависимости.
Регрессионный тест сначала воспроизвёл ошибку. Исправление использует
up -d --no-deps --no-recreate --pull never --wait для сохранённых сервисов.
Все 42 теста backup/verifier прошли без пропусков; bash syntax и Ruff прошли.

После исправления настоящий сценарий прошёл на Docker 29.9.1/Compose 5.6.0,
uid 1000 и SecurityOptions name=rootless. Unix-сокет не публиковался.
Источник и восстановление используют разные PostgreSQL/MinIO тома.
Сравнено содержимое всех 111 таблиц до запуска восстановленного приложения,
10 000 заказов, три объекта по контрольным суммам/размеру с реестром БД,
две сохранённые версии, metadata/tags и публичные/приватные политики.
Активный writer успел выполнить 16 записей до остановки и продолжил после бэкапа.
Сохранены ID контейнеров, времена запуска завершённых setup jobs и выключенный
notification-worker. История 24 заказа, receipt с русским текстом, избранное
и корзина 1580 ₽ проверены напрямую и через настоящий Next. Проверка повторена
после restart API с остановленным Redis. Следующий order ID 10001.

Исходный снимок 1693 файлов проверен до и после операции. Использованы точные
amd64 образы предыдущего полного Linux gate через binfmt; их архивы,
manifest/config digest и слои сверены. Runtime-код приложения не менялся.
После полного suite 1406/0skip изменены только backup-server.sh и его unit-тест:
42 профильных теста и настоящий restore относятся к этому исправлению;
полный suite и сборка образов после него ещё не повторялись. В backend-образе
остаётся старая копия unit-теста; актуальный backup-скрипт выполнялся из
проверенного нового снимка deploy/. Исторические отчёты не переписаны.

Все свои контейнеры, сети, тома, VM с дисками и приватная конфигурация удалены.
Рабочие данные не читались. GitHub Actions, cutover/возврат прежнего приложения,
restore на рабочем объёме и публичный browser E2E остаются открытыми.
